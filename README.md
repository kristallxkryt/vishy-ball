# Высший балл

Backend платформы подготовки к ЕГЭ на **FastAPI** и **SQLite**.

## Требования

- Python 3.11 или новее
- pip

## Установка и запуск

```bash
python -m venv .venv
```

Активация окружения:

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
```

**Linux / macOS**
```bash
source .venv/bin/activate
```

Установка зависимостей и запуск API:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

После запуска:

- API: http://127.0.0.1:8000
- Swagger: http://127.0.0.1:8000/docs
- OpenAPI: http://127.0.0.1:8000/openapi.json

При первом импорте приложения модули создают необходимые таблицы в SQLite-файле `users.db` и выполняют предусмотренные миграции.

## Основные модули

| Файл | Назначение |
| --- | --- |
| `main.py` | Создание FastAPI-приложения и подключение роутеров |
| `auth_routes.py` | Регистрация, вход, сессии и роли |
| `users_routes.py` | Административное управление пользователями |
| `classes_routes.py` | Классы, участники и приглашения |
| `variants_routes.py` | Варианты учителей и назначенные работы |
| `tasks_routes.py` | Каталог заданий и предметов |
| `checking_routes.py` | Проверка ответов, баллы и ручная проверка |
| `profile_routes.py` | Прогресс, история и статистика ученика |
| `admin_routes.py` | Управление каталогом и аналитика |
| `recommendations_routes.py` | Рекомендации по результатам ученика |
| `database.py` | Совместимый вспомогательный модуль SQLite |

## Роли

- **Ученик** — самостоятельная практика, личная статистика и выполнение работ своего класса.
- **Учитель** — создание классов, приглашение учеников, составление вариантов и просмотр результатов назначенных работ.
- **Администратор** — управление пользователями, каталогом заданий и общей аналитикой. Публичная регистрация администратора запрещена.

## Назначенные работы

- На одно назначение создаётся не более одной попытки ученика.
- Ответы сохраняются по мере выполнения.
- Незавершённую попытку можно продолжить после повторного входа.
- Закрытие назначения запрещает новые попытки, но не прерывает уже начатые.
- После отправки изменить ответы или отправить работу повторно нельзя.
- Автоматические и ручные проверки учитываются отдельно.
- Учитель видит только работы, назначенные им своим классам; самостоятельная практика ученика остаётся личной.

## Проверки

Локальный запуск интеграционных тестов:

```bash
pip install pytest
pytest -q
```

GitHub Actions автоматически проверяет компиляцию Python-модулей, импорт приложения, наличие ключевых API-маршрутов и основной сценарий работы учителя и ученика.

## Данные и безопасность

- Не добавляйте в Git реальные базы SQLite, резервные копии, файлы окружения или секреты.
- Файл `.gitignore` исключает локальные базы `*.db`, `*.sqlite`, `*.sqlite3` и файлы окружения.
- Игнорирование через `.gitignore` не прекращает отслеживание файлов, которые уже были добавлены в Git. Перед публикацией проверьте историю репозитория и удалите из неё конфиденциальные данные, если они туда попали.
- Пароли хранятся в виде PBKDF2-хешей, токены сессий и приглашений — в виде SHA-256-хешей.
