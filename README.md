# Высший балл

Платформа подготовки к ЕГЭ. Backend — **FastAPI + SQLite**, frontend — **Next.js 15 + React 19 + TypeScript + Tailwind CSS**.

## Структура проекта

- Корень репозитория — backend API и интеграционные тесты.
- `frontend/` — отдельное Next.js-приложение.
- Backend API: авторизация, каталог заданий, проверка ответов, прогресс, аналитика, классы и назначенные варианты.

## Backend: установка и запуск

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
```

Активация окружения:

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
```

**Linux / macOS**
```bash
source .venv/bin/activate
```

Установка зависимостей и запуск API:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

- API: http://127.0.0.1:8000
- Swagger: http://127.0.0.1:8000/docs
- OpenAPI: http://127.0.0.1:8000/openapi.json

## Frontend: установка и запуск

Требуется Node.js 20.9 или новее.

```bash
cd frontend
npm install
```

Скопируйте `.env.example` в `.env.local` и при необходимости укажите адрес backend:

```env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

Запуск в режиме разработки:

```bash
npm run dev
```

Откройте http://localhost:3000.

Проверка production-сборки:

```bash
npm run typecheck
npm run build
```

## Возможности интерфейса

- Адаптивная тёмная главная страница.
- Вход и регистрация ученика или учителя через FastAPI.
- Личный кабинет с реальными данными пользователя.
- Каталог предметов из backend API.
- Карточки прогресса на основе статистики API.

Демонстрационные графические элементы на главной странице помечены как пример данных. Они не выдаются за реальные показатели.

## Регистрация и аккаунты

Регистрация выполняется сразу после проверки логина, адреса электронной почты и пароля. Подтверждение по почте и автоматическая отправка писем не используются. Адрес электронной почты сохраняется как контактное поле аккаунта и может использоваться для входа.

## Основные backend-модули

| Файл | Назначение |
| --- | --- |
| `main.py` | Создание FastAPI-приложения и подключение роутеров |
| `auth_routes.py` | Регистрация, вход, сессии и роли |
| `users_routes.py` | Административное управление пользователями |
| `classes_routes.py` | Классы, участники и приглашения |
| `variants_routes.py` | Варианты учителей и назначенные работы |
| `tasks_routes.py` | Каталог заданий и предметов |
| `checking_routes.py` | Проверка ответов, баллы и ручная проверка |
| `profile_routes.py` | Прогресс, история и статистика ученика |
| `admin_routes.py` | Управление каталогом и аналитика |
| `recommendations_routes.py` | Рекомендации по результатам ученика |
| `database.py` | Вспомогательный модуль SQLite |

## Роли и назначенные работы

- Ученик — самостоятельная практика, личная статистика и выполнение работ своего класса.
- Учитель — создание классов, приглашение учеников, составление вариантов и просмотр результатов назначенных работ.
- Администратор — управление пользователями, каталогом заданий и общей аналитикой. Публичная регистрация администратора запрещена.
- На одно назначение создаётся не более одной попытки ученика.
- Ответы сохраняются по мере выполнения; незавершённую попытку можно продолжить.
- Закрытие назначения запрещает новые попытки, но не прерывает уже начатые.
- Самостоятельная практика ученика остаётся личной.


## Данные и безопасность

- Не добавляйте в Git реальные базы SQLite, резервные копии, файлы окружения или секреты.
- `.gitignore` исключает локальные базы SQLite и файлы окружения.
- Игнорирование через `.gitignore` не прекращает отслеживание уже закоммиченных файлов.
- В текущей рабочей ветке сохранены исторические тестовые SQLite-файлы до финальной проверки и очистки данных. Перед публичным production-релизом необходимо отдельно проверить их содержимое и историю Git.
- Пароли хранятся в виде PBKDF2-хешей, токены сессий и приглашений — в виде SHA-256-хешей.
